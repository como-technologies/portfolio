# Iteration changelog

One entry per iteration, written at the iteration's close: what shipped,
the **badge moves** with the evidence that gated them, and the
**corrections** the iteration forced on earlier claims. A badge never
moves here without its evidence link.

## The ledger reset (2026-07-28)

The portfolio went harness-first (ADR-0010): the knowledge base is the
content product, tools are its heads, and the clonable-template era ended.
The pre-pivot iteration entries — four iterations of build-out, three
full-loop capstone runs, and the badge climbs they gated — describe a
suite shape that no longer exists, so this ledger restarts here; the
prior entries, like everything else, live in git history. Current badges
and their gating evidence are stated where they always were: each app's
chapter, pinned by `scripts/verify-claims` against each repo's own
reality.

The next entry lands at the close of the first post-pivot iteration.
